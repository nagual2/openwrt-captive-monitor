🚀 БЫСТРЫЙ СТАРТ:

   1. Перезагрузите VS Code
      Ctrl+Shift+P -> "Developer: Reload Window"

   2. Откройте Continue
      Нажмите Ctrl+L

   3. Выберите модель
      "Grok 4.1 Fast (Free)" из списка

   4. Начните чат!
      Задайте вопрос на русском языке
