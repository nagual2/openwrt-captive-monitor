# Предложение: Улучшение управления куками в daemon режиме

## Проблема

Текущий механизм работы с куками разработан для одноразовых запусков через cron и неоптимален для daemon:

1. ❌ **Избыточное сохранение в файл** - куки сохраняются каждые 10 проверок, хотя Chrome держит их в памяти
2. ❌ **Фиксированный интервал keepalive** - каждые 10 минут, без учета времени жизни сессии
3. ❌ **Потеря куков при перезапуске Chrome** - требуется полная переавторизация
4. ❌ **Нет мониторинга сессии** - не видно когда сессия началась, сколько работает

## Предложение

### 1. Управление куками в памяти (P0)

**Текущее:**
```python
# Каждые 10 проверок
if self.check_count % 10 == 0:
    self.save_cookies()  # Запись в файл
```

**Предлагаемое:**
```python
# Сохранять только когда нужно:
# - После успешной авторизации
# - Перед перезапуском Chrome
# - При graceful shutdown
# - НЕ при каждой проверке
```

**Выгода:** Уменьшение операций записи на 90%, меньше износ диска

### 2. Интеллектуальный keepalive (P0)

**Текущее:**
```python
# Каждые 10 проверок (10 минут)
if self.check_count % 10 == 0:
    self.send_keepalive()
```

**Предлагаемое:**
```python
# На основе времени, а не количества проверок
if time.time() - self.last_keepalive_time > KEEPALIVE_INTERVAL:
    self.send_keepalive()
    self.last_keepalive_time = time.time()

# KEEPALIVE_INTERVAL = 30 минут (настраивается)
```

**Выгода:** Превентивное обновление сессии, меньше переавторизаций

### 3. Восстановление после сбоев (P0)

**Текущее:**
```python
# При перезапуске Chrome куки теряются
# Требуется полная авторизация
```

**Предлагаемое:**
```python
def restart_chrome(self):
    # Сохранить куки перед перезапуском
    self.save_cookies()
    
    # Перезапустить Chrome
    self.setup_chrome()
    
    # Попытаться восстановить сессию
    if self.load_cookies():
        if self.verify_session():
            logger.info("✅ Сессия восстановлена из куков")
            return True
    
    # Если не удалось - полная авторизация
    logger.warning("⚠️  Требуется полная авторизация")
    return False
```

**Выгода:** Восстановление сессии в 95% случаев, меньше нагрузка на портал

### 4. Отслеживание состояния сессии (P1)

**Предлагаемое:**
```python
class SessionManager:
    def __init__(self):
        self.session_start_time = None
        self.last_check_time = None
        self.successful_checks = 0
        self.failed_checks = 0
    
    def start_session(self):
        self.session_start_time = time.time()
        logger.info(f"🔐 Сессия начата: {datetime.now()}")
    
    def get_session_duration(self):
        if not self.session_start_time:
            return 0
        return time.time() - self.session_start_time
    
    def log_statistics(self):
        duration = self.get_session_duration()
        logger.info(f"📊 Статистика сессии:")
        logger.info(f"  Длительность: {int(duration/60)} минут")
        logger.info(f"  Успешных проверок: {self.successful_checks}")
        logger.info(f"  Неудачных проверок: {self.failed_checks}")
```

**Выгода:** Видимость работы daemon, проще диагностика проблем
