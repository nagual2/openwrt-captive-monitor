## Проблемы и решения

### Проблема 1: Зависание на 81% загрузки
**Симптом:** Процесс застревал на 81% загрузки SDK
**Причина:** Ограничения вывода Docker при использовании axel
**Решение:** Перезапуск с `--progress=plain` для упрощения вывода

### Проблема 2: Переполнение логов Docker
**Симптом:** `[output clipped, log limit 2MiB reached]`
**Причина:** Слишком подробный вывод axel в Docker логах
**Решение:** Использование `--progress=plain` флага

### Проблема 3: Отсутствие отладочной информации в параллельной сборке
**Симптом:** PowerShell jobs не показывали вывод Docker
**Причина:** Фоновые задачи подавляли stdout
**Решение:** Переход на прямые `controlPwshProcess` вызовы
