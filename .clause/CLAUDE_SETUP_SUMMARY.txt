🚀 БЫСТРЫЙ СТАРТ (3 ШАГА):

1. ПОЛУЧИТЬ API КЛЮЧ
   → Перейдите на https://console.anthropic.com/keys
   → Создайте новый API ключ
   → Скопируйте его

2. УСТАНОВИТЬ КЛЮЧ
   → Откройте PowerShell
   → Выполните: .\setup-claude.ps1
   → Следуйте инструкциям

3. ПЕРЕЗАГРУЗИТЬ VS CODE
   → Закройте VS Code полностью
   → Откройте VS Code заново
   → Начните использовать Claude!
